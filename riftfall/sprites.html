Sheet format

Each character animation is one sheet: columns are frames, rows are facing directions in the order E, SE, S, SW, W, NW, N, NE (row × 45°, with y pointing down). Character frames are 160×160 px (the mech is 208×208) at 2 px per world unit. The anchor point is where the feet touch the ground.

Effect sheets are a single row of frames. atlas.json lists every file with its frame size, frame count, fps, loop flag, anchor and blend mode (lighter for energy effects, normal for smoke and debris).

All art is generated from one 2.5D rig per character, so every direction matches. To change a design and re-export everything, edit tools/spritegen.
